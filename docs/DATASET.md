# Emberline dataset

The published files live in `web/public/data/` and are served at
`https://emberline-ten.vercel.app/data/<file>`. `manifest.json` is the
authoritative index: for every file it records the size, SHA-256, rows, columns
with types and units, time span and fit version. It is regenerated by
`scripts/build_manifest.py` and checked by `scripts/check_data_contract.py`.
Coverage and scale figures (countries, years, detections processed) are in
`dataset.json` (`scripts/build_dataset_card.py`) and shown on `/data`.

## Provenance chain

1. **Source.** NASA FIRMS country archive files: MODIS Collection 6.1 (Terra,
   Aqua) and VIIRS 375 m Suomi-NPP, one CSV per country, source and year
   (`scripts/stage_global.sh`). No API key is needed for the archive.
2. **Filters** (`scripts/build_tables.py`, unchanged for every country):
   vegetation fires only (`type` 0), confidence nominal or high (MODIS ≥ 30),
   daytime only, FRP present and > 0. Local solar time is computed per
   detection as UTC + longitude/15.
3. **Aggregation** (`scripts/run_global.py`): per country and per H3
   resolution-2 cell, monthly counts and FRP sums by sensor →
   `calendar_raw_global.parquet`.
4. **Fit** (`scripts/fit_harmonization.py`): per country, a logistic model of
   the chance that Aqua MODIS also detects a fire Suomi-NPP VIIRS saw, as a
   function of log FRP, trained on 2012–2018 and scored on 2019–2021; κ
   rescales the summed probabilities to Aqua's count. Countries with fewer than
   5,000 training VIIRS detections borrow the pooled curve. Result:
   `params_global.json`.
5. **Harmonized calendars**: Aqua counts to 2011; κ × Σ P(FRP) over Suomi-NPP
   detections from 2012 → `calendar_harmonized_global.parquet` and its CSV
   export `calendar_harmonized_countries.csv`.
6. **Summaries** derived from the above: `countries.json`, `season.json`,
   `drift.json`, `coverage_status.json`, `validation_points.json`,
   `harmonized_uncertainty.json`, `transfer_validation.json`, `proof.json`,
   `dataset.json`.
7. **Separate, never harmonized**: `live.json` (FIRMS near-real-time, last 24 h
   and 7 days, NOAA-20/21 VIIRS and MODIS), `current_month.json` and
   `month_to_date.json` (provisional raw counts for the current month).

## Main schemas

`calendar_raw_global.parquet`

| column | type | meaning |
|---|---|---|
| scope | String | `country` (key = FIRMS country name) or `h3_parent` (key = H3 resolution-2 cell) |
| key | String | country name or H3 res-2 cell index |
| year | Int16 | UTC calendar year |
| month | Int8 | UTC calendar month, 1–12 |
| sensor | String | `MODIS` (Terra + Aqua) or `VIIRS` (Suomi-NPP) |
| n_detections | Int64 | count of filtered detections |
| frp_sum_mw | Float64 | sum of per-detection FRP, MW (a sum, not an energy) |

`calendar_harmonized_global.parquet`

| column | type | meaning |
|---|---|---|
| scope, key, year, month | as above | |
| n_harmonized | Float64 | Aqua-MODIS-equivalent daytime vegetation-fire detections (may be fractional) |

`calendar_harmonized_countries.csv`: the `scope = 'country'` rows of the
harmonized calendar as `country,year,month,n_harmonized`, after three `#`
comment lines (fit version, unit, source).

`cell_day.parquet` (first four countries only): `h3` (res 5), `h3_parent`
(res 2), `acq_date`, `year`, `month`, `doy`, `sensor`, `platform`,
`n_detections`, `frp_sum_mw`, `frp_mean_mw`, `frp_max_mw`,
`mean_pixel_area_km2`, `mean_lst_hours`. Sorted by `h3_parent` then date, so a
range read filtered on the parent fetches only the needed row groups.

The calendar Parquet files hold both country rows and H3 grid rows over the
same detections: filter to one scope before summing. Column-level detail for
every JSON file is in `manifest.json`.

## Versioning

Every fit carries a version string (currently `v1-20261114T1240`), written into
`params_global.json` and every file derived from it. `manifest.json` groups
files into datasets (`world`, `fallback_four_country`, `live`) and refuses to
list a dataset whose files carry different fit versions; the app does not mix
files from different fits. The four-country files (`params.json`,
`calendar_raw.parquet`, `calendar_harmonized.parquet`) are an older fallback
with their own version.

## Known limits

- Fitted per country, standing in for region; no land-cover split. 171
  countries harmonized: 130 with their own fit, 41 with a pooled fit (one
  shared curve); 66 shown raw (too few detections to fit; reasons in
  `coverage_status.json`).
- Held-out R² is below 0 for some countries (counts on `/method`); a single
  country-wide ratio is about as good as the model by median held-out R².
- Matching is by day and ~3.5 km proximity, not pixel footprints.
- Daytime vegetation fires only.
- The fit uses the frozen-orbit years. Terra and Aqua drift from 2022; the
  harmonized record from 2012 is built from Suomi-NPP and does not use them,
  but 2022–2025 Aqua comparisons are affected.
- 2026 appears only in the provisional raw files, never in the harmonized
  record. Live and current-month counts come from different platforms
  (NOAA-20/21) than the Suomi-NPP history.
- Claims are regional; there is no corrected global total.

## Other sources

- NASA FIRMS area API (keyed, `FIRMS_MAP_KEY` from the environment only):
  `month_to_date.json` (`scripts/build_month_to_date.py`).
- NASA GIBS / EOSDIS true-colour imagery (NOAA-20 VIIRS corrected
  reflectance), an optional Explorer map layer:
  https://www.earthdata.nasa.gov/engage/open-data-services-software/earthdata-developer-portal/gibs-api
- NASA EONET open wildfire events, an optional globe layer: `eonet.json`
  (`scripts/build_eonet.py`), https://eonet.gsfc.nasa.gov/
- Natural Earth 1:110m country outlines (public domain),
  `web/public/geo/countries.geojson`: hotspot and month-to-date membership and
  the approximate land areas behind `land_area_km2` / `harm_per_10k_km2_yr`
  in `countries.json` (`scripts/build_density.py`),
  https://www.naturalearthdata.com/
- Orbital elements: CelesTrak via tle.ivanstanojevic.me (`tle.json`).
